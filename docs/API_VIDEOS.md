# API: список видео (лента)

Запрос: **`GET {API_BASE_URL}/videos`**  
Пример: `https://youtube.esl.kz/api/v1/videos`

Заголовок: `Accept: application/json`

## Форматы ответа (поддерживаются оба)

### 1) Обёртка Laravel `data`

```json
{
  "data": [
    {
      "id": 1,
      "title": "Заголовок",
      "playback_url": "https://example.com/video.mp4",
      "thumbnail_url": "https://example.com/thumb.jpg",
      "channel_name": "Канал",
      "views_text": "1.2K views",
      "published_text": "2 days ago",
      "duration_text": "6:03"
    }
  ]
}
```

### 2) Массив в корне

```json
[
  {
    "title": "...",
    "playback_url": "...",
    "thumbnail_url": "...",
    "channel_name": "...",
    "views_text": "...",
    "published_text": "..."
  }
]
```

## Поля

| Поле | Обязательно | Примечание |
|------|-------------|------------|
| `playback_url` | да* | Прямая ссылка на mp4 / HLS (или `playbackUrl`, `video_url`) |
| `thumbnail_url` | желательно | Превью |
| `title` | да | |
| `channel_name` | да | |
| `views_text` | да | Любая строка для UI |
| `published_text` | да | Текст или дата строкой |
| `duration_text` | нет | Например `6:03` |
| `id` | нет | Для будущего |

\* Записи без валидного `http(s)` URL воспроизведения **отфильтровываются**.

### Относительные пути

Если в JSON приходит, например, `"/storage/videos/abc.mp4"` (без `https://`), приложение **дополняет** его доменом из `API_BASE_URL` (берётся `https://youtube.esl.kz` и т.п.). Убедитесь, что такой URL реально отдаёт файл в браузере.

### Почему новое видео не видно сразу

1. **Кэш в приложении** — потяните ленту вниз (**обновить**) или перезапустите страницу.
2. **API не отдаёт запись** — проверьте в браузере: `GET https://…/api/v1/videos` и убедитесь, что объект нового видео есть в JSON.
3. **Нет поля с URL** — см. таблицу полей; можно использовать вложенные `media.url`, `attributes.playback_url` и т.д.
4. **Пагинация** — сейчас клиент читает **первую** страницу ответа; если новые ролики только на 2-й странице, их не будет в ленте (нужен бэкенд «все видео» или доработка клиента).

На стороне Laravel: отдавайте URL, которые **доступны с клиента** (CORS для медиа при необходимости).
