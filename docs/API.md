# REST API (клиент YouTube ESL)

Базовый URL задаётся в `lib/core/api_config.dart` (`API_BASE_URL`, по умолчанию `https://youtube.esl.kz/api/v1`).

## Видео

- Список и поля ответа, вложенный объект **`channel`** (или `null`), query-параметр **`?channel={slug}`** — см. **[API_VIDEOS.md](API_VIDEOS.md)**.
